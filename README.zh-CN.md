# Audio to Text · 录音转文字

**把 MP3 / M4A 录音转成文字，导出 TXT、Word、Markdown。支持中文和英文。**

**[直接打开免费网页](https://608tt.github.io/audio-to-text/)** · [English](README.md)

选择录音 → 选择语言 → 点击「开始转文字」→ 下载。
无需注册、API 密钥或按分钟付费；识别在自己的电脑上进行。
只输出识别文字，不做总结、翻译或润色。

## 直接用网页

建议用新版电脑版 Chrome / Edge。首次识别需下载开源模型，随档位、设备和说话人模式
需要几十到数百 MB；以后浏览器缓存可用时会复用。请保持页面打开，处理速度取决于电脑。
自动模式优先使用 GPU，失败会改用 CPU；也可手动选择 CPU。

音频不上传给识别服务器。网站与模型下载服务器会收到正常访问记录，例如 IP 地址。
没有账号、跟踪分析或转录历史。模型从 Hugging Face 下载，需要能访问该服务。

## 说话人选项

- **不区分（默认）**：纯文字，没有说话人或时间标签。
- **自动区分（实验）**：60 秒以内、最多 3 位说话人的短录音；标签可能出错，需要核对。
  使用带词级时间戳的标准模型，无法识别真实姓名，缺失的归属会标成不确定。
- **双声道分别识别**：适合两个人各占一个声道的录音，输出左/右声道标签。
  普通立体声会议录音通常不能据此区分人物。

长篇单声道会议可先使用不区分模式，或切分短片段使用实验区分功能。

## 本机运行

安装 [Node.js 22+](https://nodejs.org/)，下载仓库 ZIP 并解压，在目录中执行：

```sh
npm install --ignore-scripts
npm run dev
```

打开终端显示的本机网址。无需安装 Python、FFmpeg 或 GPU 环境，也不需要 Git。
首次使用模型仍需联网。不要直接双击 `index.html`，浏览器工作线程需要 HTTP 页面。

## 导出和限制

TXT 和 Markdown 按编辑框里的文字原样保存，不额外生成报告标题。
Word 是真正的 `.docx`，保留段落和空行，清除 XML 无法表示的字符。
你可以自行校对后导出；程序不做自动加工。

支持浏览器能解码的普通 MP3、M4A（AAC）和 WAV。单文件上限为 200 MB、30 分钟，
用于约束内存；并不代表所有电脑都通过了 30 分钟文件测试。
建议用电脑，手机可能内存不足。受保护的 M4A 不支持。
识别可能误听人名、漏字或在静音时产生文字，重要内容请核对。

测试、实际录音验证和适用范围见[验证记录](docs/validation.md)。
